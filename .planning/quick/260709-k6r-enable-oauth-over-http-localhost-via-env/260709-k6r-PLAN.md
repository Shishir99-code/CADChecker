<objective>
Enable the Onshape OAuth flow to work over plain `http://localhost` in local dev (no HTTPS tunnel), by making the express-session cookie flags environment-aware. Today `src/server/index.ts` hardcodes `{ httpOnly: true, secure: true, sameSite: "none" }`; browsers refuse a `Secure` cookie over http, so the passport-onshape `state: true` CSRF value never round-trips and the callback fails. This unblocks local OAuth now that the ngrok tunnel is network-blocked and deployment is deferred.
</objective>

<tasks>

<task type="auto">
  <name>Task 1: Derive session cookie secure/sameSite from redirect-URI scheme</name>
  <files>src/server/session-cookie.ts (new), src/server/session-cookie.test.ts (new), src/server/index.ts</files>
  <action>
    Create a small pure helper module `src/server/session-cookie.ts` exporting:
    `export function deriveSessionCookieOptions(redirectUri: string | undefined): { httpOnly: true; secure: boolean; sameSite: "none" | "lax" }`.
    Rule:
    - If `redirectUri` starts with `https://` → `{ httpOnly: true, secure: true, sameSite: "none" }` (UNCHANGED production/tunnel behavior — required so the session cookie is sent from inside the cross-origin Onshape Element Tab iframe; RESEARCH Pitfall 2 / ASVS V3).
    - Otherwise (http://localhost dev, or unset) → `{ httpOnly: true, secure: false, sameSite: "lax" }` so the browser actually sets the cookie and the passport `state` CSRF value round-trips locally.
    Include a concise comment explaining both branches and that http-scheme redirect URIs relax the flags for local dev only.

    In `src/server/index.ts`, replace the inline `cookie: { httpOnly: true, secure: true, sameSite: "none" }` object with `cookie: deriveSessionCookieOptions(ONSHAPE_REDIRECT_URI)` (import the helper). Keep the surrounding sessionOptions (secret/resave/saveUninitialized) and everything else in index.ts unchanged. Preserve/relocate the existing explanatory comment.

    Write `src/server/session-cookie.test.ts` (vitest) asserting:
    - `deriveSessionCookieOptions("https://foo.example/auth/onshape/callback")` → `{ httpOnly: true, secure: true, sameSite: "none" }`
    - `deriveSessionCookieOptions("http://localhost:5173/auth/onshape/callback")` → `{ httpOnly: true, secure: false, sameSite: "lax" }`
    - `deriveSessionCookieOptions(undefined)` → the http/relaxed variant (safe default)
    Match the existing vitest import + describe/it conventions used elsewhere under src/server.
  </action>
