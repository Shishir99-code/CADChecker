<objective>
Close the two blocking verification gaps that make the frame-perimeter check (GEOM-01/GEOM-02)
non-functional against a real Onshape document, without touching the already-verified
starting-height path (GEOM-03).

Gap 1 (CR-01): `flattenAssembly()` sets `Fact.partId` to the occurrence's leaf INSTANCE id,
never resolving it to the real CAD partId via the instance map (03-BOUNDING-BOX-CONTRACT.md G1).
The route's 5c/5b partId join against `definition.parts[]` therefore never matches on any real
document (instance id != CAD partId), so `bboxCornersWorld` is always undefined and the check
is permanently stuck in its UNKNOWN branch.

Gap 2 (CR-02): even once the join succeeds, the 5c enrichment keys `frameFactsById`/`bboxByPartId`
by partId ALONE, collapsing N occurrences of one reused FRAME_ part to the last one — silently
undersizing the hull into a false PASS (violates D-02 and G1 "include every occurrence, not one").

Purpose: make R101 produce a trustworthy PASS/FAIL/UNKNOWN on real multi-instance FRC topology.
Output: instance->partId resolution in the shared traversal, per-occurrence 5c enrichment, and
regression tests that use distinct id spaces + a two-occurrence fixture so the bug cannot silently
return.
</objective>
