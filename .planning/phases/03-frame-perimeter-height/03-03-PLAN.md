<objective>
Ship the starting-configuration height check: the whole-robot maximum +Z extent in the
default (as-modeled) configuration, compared against the R104 season limit, with the
measured configuration disclosed. Uses ONE assembly-level `getAssemblyBoundingBoxes`
call (Onshape resolves referenced documents server-side) rather than per-part calls —
because height needs the whole robot (D-05, all occurrences), and per-part-for-height
would mean 200+ calls and re-trigger Phase 2's cross-document 403 problem
(03-RESEARCH.md Pitfall 2).

Purpose: GEOM-03 — a height verdict a team can trust, honest about what and which
configuration it measured. Reuses the tri-state Verdict, `passesOperator`, and the
`M_TO_IN` conversion boundary; keeps the check pure/synchronous over enriched `Fact[]`.
Output: the assembly-level height enrichment in the route, the `Fact.robotMaxZWorld`
field, and the `startingHeightCheck` CheckFn.
</objective>
