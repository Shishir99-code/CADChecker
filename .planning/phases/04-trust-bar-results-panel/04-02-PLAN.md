<objective>
Add the "measured against" disclosure header: every check run states the document, tab/element, configuration, and timestamp it reflects — with human-readable names, not raw id hashes — so a mentor can tell at a glance whether a result is stale. The four fields are assembled in the same atomic response object as the verdicts and rendered together, making an old-geometry/new-timestamp mismatch structurally impossible.

Purpose: RSLT-03 (every verdict discloses document/tab/configuration/timestamp) + SC3 + SC4 (atomic four-field update on re-check). This is the disclosure vertical slice: new typed client call → server-side name/timestamp resolution → panel header render, end to end.
Output: a `getDocument` client method, a grown `measuredContext` carrying documentName/tabName/configurationName/checkedAt, and a DisclosureHeader component rendered above the verdict table.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| panel → /api/check | Untrusted `req.body` (documentId/workspaceId), validated by `CheckRequestSchema`; disclosure ids/names must NOT be echoed from req.body beyond the validated ids |
| /api/check → Onshape REST | New `getDocument(documentId)` server-side call; response `.name` is the authoritative display name |
| server measuredContext → DisclosureHeader | Human-readable names + timestamp rendered into the DOM |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-04 | Spoofing / Tampering | disclosed document/tab/config names | mitigate | `tabName` = server-fetched `assembly.name`; `documentName` = server `getDocument(documentId).name`; `configurationName` = server constant "Default" — none are read from `req.body` (continues CONN-02 / T-01-11 discipline; only the already-validated documentId is used as a path param) |
| T-04-05 | Tampering (XSS) | DisclosureHeader renders documentName/tabName | mitigate | Rendered via React JSX text interpolation (auto-escaped); task forbids `dangerouslySetInnerHTML`; `toLocaleString()` output is a plain string |
| T-04-06 | Information disclosure | getDocument response object | mitigate | Only `.name` is read into measuredContext; no tokens/secrets/ACL fields are copied into the response; getDocument failures leave documentName undefined (no error detail leaked) |
| T-04-07 | Denial of service / availability | best-effort getDocument | mitigate | try/catch swallows non-auth failures so a naming lookup can never fail the whole check; 401 / ReconnectRequiredError still propagate to the distinct reconnect path |
| T-04-SC | Tampering (supply chain) | npm installs | accept | This plan installs ZERO new packages (04-RESEARCH.md: getDocument reuses the existing openapi-fetch client); no legitimacy checkpoint required |
</threat_model>
